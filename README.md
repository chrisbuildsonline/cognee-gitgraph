# Cognee GitGraph

A native Cognee connector that ingests multi-branch Git commit trees, AST symbols, and CI failure logs into Cognee's persistent graph memory to calculate multi-hop blast radii and architectural drift on every pull request.

Built for [CreateAThon](https://graph-hacks.devpost.com/). Submissions close 2026-10-31.

## What it does

A native Cognee connector that ingests multi-branch Git commit trees, AST symbols, and CI failure logs into Cognee's persistent graph memory to calculate multi-hop blast radii and architectural drift on every pull request.

## Stack

Python, Cognee SDK, NetworkX, Tree-sitter, GitPython, Pytest, FastAPI
